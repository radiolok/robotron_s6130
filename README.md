# Robotron S6130 и «Элема»: прошивки, схемы, документация

Реверс-инжиниринг и восстановление электронных пишущих машинок серии
**Robotron S6100** (ГДР, 1986–1989) и их советского аналога **«Элема» (ПЭЛК-3110)**.

| Машинка | Процессор | Статус |
|---|---|---|
| **Robotron S6130** | U880 (клон Z80), 2,46 МГц | ✅ **Работает.** Новая материнская плата, разблокирован RS-232 |
| **«Элема» ПЭЛК-3110** | КР580ВМ80А (клон i8080) | 🛠 **Заготовка.** Прошивка снята, схема оцифрована, карта периферии сверена со схемой |

История оживления «Роботрона»: статья на Хабре
[«Robotron S6130 — Восставший из мертвых»](https://habr.com/ru/companies/yadro/articles/886254/).

## Структура репозитория

```
bin/        Дампы ПЗУ и дизассемблированные листинги
doc/        Документация производителя (руководства, сервисные описания, даташиты)
docs/       Описание аппаратуры и прошивок (этот проект)
jpg/        Схемы и иллюстрации
sch/        Схемы: KiCad (новая плата), DipTrace, draw.io (структурная схема)
tools/      Скрипты для анализа трасс и ПЗУ
```

### `bin/` — прошивки

| Файл | Размер | Описание |
|---|---|---|
| `s6130.1.bin` … `s6130.7.bin` | 7 × 2 КБ | Оригинальные ПЗУ S6130 (0000h–37FFh, по 800h на корпус) |
| `s6130.full.bin` | 14 КБ | Склейка `s6130.1…7.bin` — **оригинальная** прошивка |
| `s6130.full_new.bin` | 24 КБ | **Патченная** прошивка для новой платы (включены меню RS-232 и асинхронный режим SIO, см. [патчи](docs/robotron_s6130/bringup.md#патчи-прошивки)) |
| `s6130.full.bin.asm` | — | Листинг IDA с разметкой функций и комментариями |
| `s6130.full.bin.i64` | — | База IDA Pro |
| `symbol_rom.bin` | 2 КБ | ПЗУ знакогенератора платы индикации (8 байт на символ 5×7) |
| `pelk_3101.1.bin` | 8 КБ | «Элема», ПЗУ №1 (0000h–1FFFh) |
| `pelk_3110.2.bin` | 8 КБ | «Элема», ПЗУ №2 (2000h–3FFFh) |
| `pelk_3101.full.bin` | 16 КБ | «Элема», склейка двух ПЗУ |
| `pelk_3101.full.bin.asm` | — | «Элема», листинг i8080 (без разметки) |

### `sch/` — схемы

| Файл | Описание |
|---|---|
| `s6130_kicad/` | Новая материнская плата S6130 (KiCad): одна ПЗУ W27C512 и одна ОЗУ вместо 23 корпусов |
| `rft_s6130_sch.drawio` | Структурная схема и схема получения трассы (исходник `jpg/rft_s6130_sch*.png`) |

### `tools/` — инструменты

| Скрипт | Назначение |
|---|---|
| `z80_trace.py` | Превращает вывод Z80-декодера PulseView/sigrok в читаемую трассу (`.out`) и в Trace Events JSON для [Perfetto UI](https://ui.perfetto.dev) (флейм-чарт вызовов и обращений к портам) |
| `s6130_symbol.py` | Рисует таблицу символов из ПЗУ знакогенератора индикатора |
| `s6130_mem.py` | Описание карты памяти S6130 |
| `stitch_scans.py` | Склейка фрагментов скана одного листа (SIFT + аффинные преобразования; поворот и масштаб фрагментов любые). Нужен `opencv-python` |

```sh
# Трасса: export.txt — вывод декодера Z80 из PulseView, names.txt — экспорт имён функций из IDA
python3 tools/z80_trace.py -f export.txt -a names.txt              # S6130
python3 tools/z80_trace.py -f export.txt -a names.txt -m elema     # «Элема» (карта портов ПЭЛК)
# → export.txt.out (трасса) и export.txt.json (открыть в https://ui.perfetto.dev)

# Таблица символов индикатора
python3 tools/s6130_symbol.py -f bin/symbol_rom.bin -o charset.png

# Склейка листа схемы из фрагментов (--ref — номер фрагмента, задающего ориентацию)
python3 tools/stitch_scans.py -o sheet.png --ref 2 part1.jpg part2.jpg part3.jpg
```

Как устроен процесс отладки, описано в [bringup.md](docs/robotron_s6130/bringup.md#инструментарий).
