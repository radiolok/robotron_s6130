# «Элема» (ПЭЛК-3110): заготовка для оживления

«Элема» — советская версия пишущей машинки серии Robotron S6100. Механика повторяет S6100
до последнего винтика, а электроника сделана на **КР580ВМ80А** (клон Intel 8080) и других
отечественных микросхемах. На материнской плате есть посадочное место под последовательный порт.

Статус: машинка в Муромском кибер-музее. Прошивка снята. Карта периферии восстановлена по коду
и **сверена с принципиальной схемой** ([hw/README.md](hw/README.md), сканы в `hw/scans/`).
На железе ничего не проверено. Пометка *(гипотеза)* означает, что схема этого не подтверждает.

Отметки в таблицах: ✅ — подтверждено схемой, ❔ — только по коду.

## Содержимое

| Папка | Что внутри |
|---|---|
| [`fw/`](fw/) | Дампы ПЗУ (`pelk_*.bin`), листинг i8080 и [разбор прошивки](fw/README.md): карта памяти и портов, прерывания, структура |
| [`hw/`](hw/) | [Расшифровка принципиальной схемы](hw/README.md), склеенные листы `elema_sheet1.png`/`elema_sheet2.png`, исходные сканы `scans/`, [нетлисты](hw/netlist/README.md) |

Коротко об устройстве: ПЗУ 16 КБ (2× К573РФ6А, `0000h–3FFFh`), ОЗУ 4 КБ (2× КР537РУ10А, `6000h–6FFFh`),
периферия ВН59, 2× ВИ53, 2× ВВ55, ВВ51 в портах `E0h–FFh`. Плата индикации — светодиоды и зуммер,
четыре шаговых двигателя через плату ключей, электромагниты молотка и подъёма ленты.

## План оживления

### 1. Документы
- [x] Добавить в `hw/` принципиальную схему (сканы + склейка, [hw/README.md](hw/README.md)).
- [ ] Добавить инструкцию по эксплуатации.
- [ ] Отсканировать схему в 300–600 dpi: дочитать номера выводов, разряды адреса на дешифраторах, номинал кварца.
- [x] Сверить по схеме типы ПЗУ/ОЗУ, периферию и разъёмы ([hw/README.md](hw/README.md)).
- [ ] Дочитать разряды адреса на входах КР1533ИД7 (сейчас зоны выведены из прошивки).
- [x] ВВ51 (`F4h/F5h`) — последовательный порт, тактируется от ВИ53 №2 OUT1. Прошивка его
      не включает, так что для RS-232 придётся дописать код (по образцу S6130).
- [ ] Разобрать сканер клавиатуры (порт `E8h`, IR4) и источник датчиков на `F8h`
      (ДНБ, ДЛП, S1/S2?).

### 2. Электрика (прошлый опыт: «выстрел конденсатором в бок»)
- [ ] Перед подачей питания проверить электролитические и танталовые конденсаторы в БП и на плате.
- [ ] Проверить выходы БП на холостом ходу: XS1 +5 В, ±12 В, −5 В; XS2 +5 В, +24 В
      ([hw/netlist/interconnect.csv](hw/netlist/interconnect.csv)).
- [ ] Первое включение — от лабораторного источника с ограничением тока, по одной шине.
- [ ] КР580ВМ80А нужны +5 В, −5 В, +12 В и двухфазный тактовый сигнал (КР580ГФ24):
      проверить все напряжения и фазы Ф1/Ф2 до установки процессора.
- [ ] Проверить батарею ОЗУ (протечки, как у «Роботрона»).

### 3. Прошивка и ОЗУ
- [ ] Прочитать ПЗУ на месте и сверить с `fw/pelk_*.bin`.
- [ ] Проверить ОЗУ (на «Роботроне» умерла половина).

### 4. Трасса
Z80-декодер sigrok ждёт сигналов `M1`, `MREQ`, `IORQ`, `RD`, `WR`, которых у 8080 нет.
Готового декодера i8080 в sigrok, насколько известно, тоже нет. Варианты:
- [ ] Снимать сигналы после системного контроллера КР580ВК28/ВК38 (`MEMR`, `MEMW`, `IOR`, `IOW`,
      `INTA`) и защёлкнутый бит M1 слова состояния. Получится аналог `MREQ = MEMR|MEMW`,
      `IORQ = IOR|IOW`, `M1 = D5 статуса`. Опкоды 8080 — подмножество Z80, так что Z80-декодер
      их разберёт (в мнемонике Z80).
- [ ] Либо написать небольшой декодер i8080 для sigrok.
- [ ] Аннотировать трассу картой портов «Элемы»: `tools/z80_trace.py -m elema`.

### 5. Разбор кода
- [ ] Загрузить `fw/pelk_3101.full.bin` в IDA/Ghidra как 8080, базовый адрес 0.
- [ ] Разметить по аналогии с S6130: старт `018Dh`, заглушки `27C0h`, обработчики из таблицы IRQ выше.
- [ ] Найти условие «не стартую» (у S6130 это был концевик крышки): опросы `F8h` в начале
      `09BEh` (`in F8h / ani 04h`) — первый кандидат.
- [ ] Найти таблицу меню и возможные «спрятанные» функции RS-232, как у S6130.
